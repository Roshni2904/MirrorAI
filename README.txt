MirrorAI Website - Updated Purple Theme

HOW TO RUN
1. Extract MirrorAI_Website_Updated.zip.
2. Open the MirrorAI_Website_Updated folder in Visual Studio Code.
3. Open index.html using the Live Server extension (recommended), or open it in a browser.
4. Register a demo account and log in.
5. After login, use the menu to open Dashboard, My Profile, My Schedule, Weather, Ask AI Assistant, Mirror History, Reminders, Settings, Live Camera and My Photos.

PAGES ADDED
- Reminders: add, view and delete reminders.
- Settings: control greeting and activity-history preferences.
- Live Camera: preview your computer/phone camera after granting browser permission.
- My Photos: select and preview image files in the browser.

IMPORTANT
- This is a front-end student project prototype. Login data is stored in browser localStorage and is not secure for real users.
- Weather and AI responses are demo placeholders; connect real APIs through a secure backend for live functionality.
- Browser camera access generally requires localhost or HTTPS and user permission.
- Photo previews are temporary and are not uploaded to a server.
- Live Camera currently previews the browser device camera. Raspberry Pi integration requires a backend/device connection.
